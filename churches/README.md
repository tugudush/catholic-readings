# Catholic Church Schedules

This directory records local parish and cathedral information, including published Mass timetables, confession times, contact details, and links for verification. These schedules are pastoral reference data and should be confirmed with the church before travel, especially on solemnities, holidays, and during parish events.

## Source Convention

The schedules in these records were transcribed from [Mass Schedules Philippines](https://www.mass-schedules.com/), which states that its data may not be current and that transactions should be made directly with the church. Each record preserves the relevant source URL and page-update date.
